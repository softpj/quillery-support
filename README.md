# Quillery support site

Static pages for Quillery (formerly Folio): the support page and the privacy policy. Published with GitHub Pages from the `main` branch root.

- `index.html`: support, quick answers and the contact address
- `privacy.html`: the privacy policy that App Store Connect links to
- `styles.css`, `fonts/`: the site's look (DM Sans and Playfair Display, OFL licences alongside)
